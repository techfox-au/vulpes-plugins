Shared MCP server for Grok Bot and other machine clients. Settings issues a read-only bearer token, shown once, that expires after 90 days. The Expires column shows that date, and the dashboard's default mail recipients are emailed 10 days before it. Each use is written to the audit trail. The endpoint is /api/plugins/mcp. Installed plugins register their own tools on that server. Microsoft 365 Audit registers the audit log tools, so one token can search those logs and any tools another plugin adds later. Deleting a token removes it from the list and destroys the stored key. Tokens that were created in Microsoft 365 Audit are copied across the first time this plugin starts.
