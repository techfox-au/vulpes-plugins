Collects Microsoft 365 and Entra security logs from each client into the dashboard. Sign-ins, directory changes, the unified audit log, Defender alerts and incidents, Identity Protection risk, and Secure Score are each collected on their own schedule. After Vulpes starts, Secure Score is collected once as soon as Elasticsearch is ready, then returns to its interval. Statistics shows how much Elasticsearch storage those logs use, by log and by client. Grok Bot reaches these logs through the host MCP server at /api/mcp. Clients and the shared Entra application are added under Manage → Tenants. A client's directory id does not change in place. An empty application secret or certificate clears the copy stored for each client. A Graph next link that leaves Microsoft Graph fails the collection run. Secure Score leaves its watermark in place when indexing reports failures. The database is created as one schema.
