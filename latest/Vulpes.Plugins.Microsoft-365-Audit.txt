Collects Microsoft 365 and Entra security logs from each client into the dashboard. Sign-ins, directory changes, the unified audit log, Defender alerts and incidents, Identity Protection risk, and Secure Score are each collected on their own schedule. After Vulpes starts, Secure Score is collected once as soon as Elasticsearch is ready, then returns to its interval. Statistics shows how much Elasticsearch storage those logs use, by log and by client. Settings can issue a read-only token so Grok Bot can search the stored logs over MCP. Clients and the shared Entra application are added under Manage → Tenants.
