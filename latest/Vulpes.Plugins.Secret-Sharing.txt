Send a secret to someone, or collect one from them. The public reveal and upload pages use the dashboard theme, including the eye and copy controls. The browser encrypts it before upload, and the server stores only ciphertext. A link can expire, burn after it is opened, require a password, or be limited to certain IP addresses. An upload link carries the collect public key in the #pk= fragment so the browser can check it before encrypting. A maximum open count, when set, must be from 1 to 100000. Leaving it blank means no cap. Notification emails for an opened send or a ready collect stay off until the dashboard has mail configured and the account has an email address. A collect upload burns a valid proof before the collect is looked up. A send or upload whose ephemeral key does not contribute is rejected. The first email addresses for a bot link are the only recipients, and those addresses are sealed with the data key. A visitor whose IP is not allowed does not use up the proof of work. The database is created as one schema.
